# StudyRPG

A pixel-art study timer (Pomodoro-style) where every finished study session is a battle won. Earn XP to level up your hero, gold for gear, and command an idle army that raids demon keeps while you study.

**Play:** https://daneviser.github.io/StudyRPG/

```bash
npm install
npm run dev
```

## Documentation

- [Game features](docs/GAME_FEATURES.md): everything the game can do, with all numbers.
- [Technical guide](docs/TECHNICAL.md): architecture, save format, how to extend it, and the plan for backend saves and login.

Progress is stored in the browser's `localStorage`; use **Config → Export / Import** to back it up.
